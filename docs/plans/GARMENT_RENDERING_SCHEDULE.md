# 신체 확장 의상과 렌더링 최소 일정

이 문서는 현재 필요한 인체 에셋 제작을 위한 최소 범위를 정의한다. 목표는 주름·천 물리 이전에, 원본 인체 리그를 유지하면서 긴소매·바지처럼 신체를 일정량 확장한 의상을 안정적으로 편집·출력하는 것이다.

정확한 날짜보다 각 단계의 완료 조건을 우선한다. 이 문서의 작업은 스프라이트 시트·Unity 임포트 경로와 호환되어야 하며, 기존 일반 자유 도형을 강제로 의상으로 바꾸지 않는다.

## 범위와 결정

- 원본 관절과 연결 튜브는 포즈·애니메이션·선택의 구조 기준으로 계속 유지한다.
- 의상은 원본 관절 체인의 표면 규칙을 상속한 **확장 표면**이다. 별도 뼈나 자유로운 길이 변경을 만들지 않는다.
- 긴소매·반소매·바지 길이는 새 관절을 추가하지 않고, 생성한 의상 연결 면을 부모에서 자식으로 향하는 **로컬 축**에서 절단해 정한다.
- 출력에서는 의상이 원본 신체를 덮고, 편집에서는 원본 관절·튜브를 가이드로 계속 선택할 수 있다.
- 주름, 천의 처짐, 치마·망토처럼 체인 밖으로 변형되는 의상은 이 일정의 완료 뒤 작업이다.

## R0. 출력 렌더링 보정

### 목표

의상 기능을 얹기 전에 편집 화면·미리보기·PNG·SVG가 같은 실루엣과 가림 규칙을 사용하게 한다.

### 작업

1. 출력 전용 외곽선 계산을 면·관절·튜브의 실제 가시 경계로 통일한다.
2. 원근 적용에서 회전이 과도하게 보이는 사례를 분리한다. 카메라 투영, 표면 단면 회전, 월드 회전이 중복 적용되는지를 확인한다.
3. 관절 X/Y/Z 회전은 하위 관절의 3D 위치를, 튜브·관절 표면 회전은 단면의 방향을 각각 한 번만 적용하도록 변환 소유권을 정리한다. 동일한 회전이 위치와 표면에 의도 없이 중복 적용되어 과도한 비틀림·원근 왜곡을 만들지 않는지 확인한다.
4. 정면·측면·사선과 X/Y/Z 관절 회전이 있는 포즈를 PNG와 SVG로 회귀 검증한다.

### 완료 조건

- 내부선이 출력 외곽선으로 잘못 남지 않는다.
- 원근 강도를 바꿔도 관절의 회전 각도 자체가 증폭된 것처럼 보이지 않는다.
- 관절 중심, 튜브 양 끝, 표면 단면과 외곽선이 같은 3D 변환 계약을 사용하며, X/Y/Z 회전이 의도치 않게 두 번 적용되지 않는다.
- 편집 미리보기와 PNG/SVG의 가림 순서가 일치한다.

## T0. 튜브 단면 방식 검토

### 목적

신체 튜브와 의상 셸이 공유할 단면 표현을 구현 전에 비교한다. 현재 단계에서는 원, 타원 또는 원호 중 하나를 확정하지 않으며, 후보별 결과와 제약을 같은 포즈에서 확인한다.

### 검토 후보

- **원 단면:** 현재 관절 반지름과 가장 직접적으로 연결되며 회전과 셸 확장이 단순하다.
- **타원 단면:** 정면 폭과 측면 깊이를 분리할 수 있어 납작하거나 두꺼운 신체·의상 표현에 유리하다.
- **원호 기반 가시 단면:** 카메라에 실제로 보이는 외곽 구간만 만들 수 있지만, 위상 유지·끝단 캡·SVG 병합 규칙이 더 복잡해질 수 있다.
- 필요하면 타원 단면을 기본 형상으로 두고 가시 외곽만 원호로 추출하는 혼합 방식도 비교한다.

### 비교 표본

1. 정면, 좌우 45도와 완전 측면의 직선 팔·다리
2. X/Y/Z로 굽힌 팔꿈치와 무릎
3. 원근을 끈 상태와 켠 상태
4. 서로 다른 시작·끝 반지름을 가진 테이퍼 튜브
5. 긴소매와 중간 절단 소매의 끝단 캡
6. 신체 튜브 위에 일정 두께로 확장한 의상 셸

### 판단 기준

- 관절 중심, 연결 축과 단면이 같은 3D 변환·투영 계약을 사용하는가
- 시점이 변해도 단면의 꼭짓점 또는 원호 방향이 갑자기 뒤집히지 않는가
- 정면 폭, 측면 깊이와 의상 두께를 독립적으로 표현할 수 있는가
- 절단면 캡과 신체 가림 경계를 안정적으로 만들 수 있는가
- 그룹 병합 SVG와 PNG 출력이 같은 실루엣을 만드는가
- 포즈 보간 중 위상과 렌더 순서가 유지되는가
- 프레임마다 과도한 정점 재생성이나 교차 계산을 요구하지 않는가

### 임시 데이터 계약

후보 비교 동안 `TubeSection`은 특정 SVG 도형을 저장하지 않고 다음 기하 정보만 전달하는 방향으로 검토한다.

- 중심점과 부모→자식 접선 방향
- 단면의 로컬 `right/up` 기준축
- 두 기준축의 반경 또는 폭·깊이
- 닫힌 단면 여부와 가시 원호 범위
- 안정적인 시작점과 진행 방향

정확한 필드와 원·타원·원호 중 최종 방식은 비교 표본을 확인한 뒤 확정한다. 후보 검토 전에는 저장 형식과 의상 데이터에 특정 단면 방식을 고정하지 않는다.

### 완료 조건

- 같은 입력 포즈로 원·타원·원호 후보를 비교할 수 있는 최소 프로토타입 또는 계산 표본이 있다.
- 각 후보의 시점 안정성, 절단 캡, 의상 두께와 SVG 병합 장단점이 기록돼 있다.
- G1을 시작하기 전에 사용할 1차 방식과 보류할 대안이 명시돼 있다.

## T1. 허리–골반 전이 다각형 검토

### 목적

허리와 골반 사이의 연결은 아직 최종 처리 방식이 확정되지 않았다. 허리 관절 단면과 골반 측 관절 또는 가상 캡슐의 투영 외곽을 경계로 사용해 전이 다각형을 생성하고, 그 내부를 어떤 구조로 채우고 분할할지 별도로 검토한다.

### 외곽 생성 원칙

- 화면에 저장된 고정 점이 아니라 매 프레임 계산한 허리·골반 측 관절의 투영 외곽을 입력으로 사용한다.
- 각 관절 외곽에서 연결 방향에 대응하는 지지점 또는 원호 구간을 선택한다.
- 선택한 외곽 구간을 안정적인 순서로 연결해 허리–골반 전이 다각형의 바깥 경계를 만든다.
- 정면, 45도와 측면에서 좌우 순서와 꼭짓점 진행 방향이 갑자기 뒤집히지 않아야 한다.
- 체형 변경, 포즈, X/Y/Z 회전과 원근 변경 때도 같은 관절 참조와 경계 의미를 유지한다.

### 내부 처리 검토 항목

정확한 내부 방식은 아직 결정하지 않는다. 다음 후보를 비교한다.

- 하나의 단순 다각형으로 채우기
- 안정적인 대응점을 연결한 사각형 또는 삼각형 분할
- 허리·골반 외곽의 합집합과 마스크를 이용한 채움
- 좌우 전이 영역과 중앙 영역을 분리한 복수 패치
- 깊이 차나 교차가 있을 때 보이는 패치만 선택하는 방식

내부 처리는 외곽 실루엣을 바꾸지 않아야 하며, 내부선 표시 여부, 삼각형 뒤집힘, 자기 교차, 깊이 정렬과 그룹 병합 SVG에 미치는 영향을 함께 검토한다.

### 비교 표본

1. 직선형 기본체의 정면·45도·측면
2. 허리 폭과 골반 폭이 다른 체형
3. 허리 X/Y/Z 회전과 골반 월드 회전
4. 한쪽 다리를 앞으로 보내 좌우 고관절 깊이가 달라진 포즈
5. 허리·골반을 덮는 상의와 바지 셸이 만나는 표본

### 임시 결과물

- 허리 외곽과 골반 측 외곽에서 선택한 경계 구간
- 안정적인 꼭짓점 또는 원호 대응 규칙
- 외곽 다각형과 내부 패치 후보를 분리한 계산 결과
- 자기 교차, 퇴화 면과 순서 뒤집힘을 보고하는 검증 결과

### 완료 조건

- 각 관절 외곽을 경계로 하는 허리–골반 전이 다각형이 기준 시점에서 생성된다.
- 외곽 생성과 내부 채움·분할이 별도 단계로 분리돼 있다.
- 내부 처리 후보의 실루엣, 위상 안정성, 깊이 정렬과 SVG 병합 장단점이 기록돼 있다.
- G1을 시작하기 전에 사용할 1차 내부 처리 방식 또는 제한된 초기 범위가 정해져 있다.

## T2. 가슴·몸통 전이 표면 검토

### 목적

가슴과 상체는 어깨 캡슐, 가슴 관절과 허리 단면 사이를 연결해야 한다. 현재 몸통 사각형은 직선형 기본체에는 충분하지만, 체형·회전·원근 변화에서 가슴 외곽과 내부 표면을 안정적으로 표현하는 최종 방식은 아니다. 새 외곽은 단순한 어깨 연결면이 아니라 **어깨에서 아래로 이어지는 갈비뼈·흉곽의 실루엣**을 담당한다.

### 외곽 생성 원칙

- 좌우 어깨의 안쪽 캡슐 외곽, 가슴 관절 외곽과 허리 단면 외곽을 입력으로 사용한다.
- 측면 가슴 실루엣의 1차 방향은 어깨에서 시작하는 **둥근 사각형** 형태로 한다. 단순한 네 점 사다리꼴 대신 앞가슴·등과 위·아래 모서리의 곡률을 가진 외곽을 사용한다.
- 둥근 사각형은 어깨 관절 자체의 외곽을 복제하는 도형이 아니라, 어깨 아래에서 시작해 갈비뼈의 앞·뒤·아래 경계를 나타내는 흉곽 외곽이다.
- 둥근 사각형의 상단 폭·깊이는 좌우 어깨 안쪽 캡슐과 가슴 깊이에서 파생하고, 모서리 반경은 체형별로 조절할 수 있게 검토한다.
- 상체가 회전할 때 둥근 사각형은 화면에 고정된 2D 도형이 아니라 가슴 로컬 기준축을 따르는 단면 또는 표면으로 회전·투영한다.
- 정면에서는 어깨선·흉곽 폭·허리 폭을 연결하는 상체 실루엣을 만든다.
- 45도와 측면에서는 앞가슴·등 쪽 깊이와 좌우 어깨 가림 순서를 반영한다.
- 가슴과 허리 사이의 외곽 대응점 또는 원호 구간은 시점 변화 중 순서가 뒤집히지 않아야 한다.
- 화면 좌표를 저장하지 않고 관절·캡슐·단면에서 매 프레임 다시 계산한다.

### 내부 처리 후보

- 어깨의 둥근 사각형 외곽을 허리 단면으로 로프트하는 기본 방식
- 외곽 전체를 하나의 단순 다각형으로 채우는 방식
- 좌우 가슴과 중앙 흉곽을 분리한 복수 패치
- 어깨–가슴, 가슴–허리를 별도 전이 패치로 나누는 방식
- 단면 대응점을 잇는 삼각형 또는 사각형 분할
- 관절 외곽의 합집합과 마스크로 내부 접합선을 제거하는 방식

정확한 내부 처리와 가슴 면 개수는 표본을 확인한 뒤 결정한다. 내부 패치는 외곽 실루엣과 독립적으로 교체할 수 있어야 한다.

### 흉곽 외곽의 임시 입력

- 좌우 어깨 안쪽 캡슐에서 가져온 상단 앵커
- 가슴 로컬 중심과 `right/up/forward` 기준축
- 정면 흉곽 폭, 측면 흉곽 깊이와 세로 길이
- 앞가슴·등·아래 갈비뼈에 대응하는 모서리 반경
- 허리 단면으로 좁아지기 시작하는 하단 연결 범위

이 값은 화면의 둥근 사각형 좌표를 저장하기 위한 것이 아니라, 매 프레임 로컬 흉곽 외곽과 가시 원호를 다시 계산하기 위한 입력 후보이다.

### 비교 표본

1. 직선형·역삼각형·사다리꼴 체형의 정면
2. 좌우 45도와 완전 측면
3. 상체 X/Y/Z 굽힘과 월드 회전
4. 어깨 폭·가슴 깊이·허리 폭이 크게 다른 표본
5. 상의 셸이 가슴과 허리를 함께 덮는 표본
6. 둥근 사각형의 모서리 반경이 작은 체형과 큰 체형

### 완료 조건

- 어깨·가슴·허리 외곽을 경계로 하는 상체 전이 표면 표본이 있다.
- 측면에서 둥근 사각형 기반 가슴 외곽이 앞가슴·등 깊이와 모서리 곡률을 유지한다.
- 외곽 생성과 내부 패치 계산이 분리돼 있다.
- 가슴 앞·옆·뒤의 깊이와 가림 순서를 표현할 초기 범위가 정해져 있다.
- T1 허리–골반 표면과 연결했을 때 틈, 중복 외곽선과 자기 교차가 없다.

## F0. 얼굴 면 기본 구조

### 목적

현재 머리는 `head` 관절에 연결된 구형 도형이 중심이며, 캐릭터를 완성하려면 눈·코·입·볼·턱과 같은 얼굴 요소가 붙을 기준 면이 필요하다. 얼굴 면은 머리 구 자체를 대체하지 않고 머리의 로컬 좌표와 시점 변화를 따르는 별도 표면 계층으로 추가한다.

### 1차 범위

- 얼굴 정면의 기본 면 또는 중앙 패치
- 좌우 볼·측면과 턱 경계를 표현할 최소 면
- 눈·코·입 도형이 참조할 안정적인 로컬 기준점 또는 UV 성격의 좌표
- 머리 관절 이동·회전, 체형과 월드 회전을 따르는 바인딩
- 정면·좌우 45도·측면에서 필요한 표시·가림 순서

### 설계 원칙

- 여기서 얼굴 면은 캐릭터의 얼굴 표면을 뜻하며, 기존 관절 연결 데이터 타입 `Face`로 확정한 용어가 아니다. `ArtShape` 확장, 별도 표면 타입 또는 복수 패치 중 데이터 표현은 표본 뒤 결정한다.
- 얼굴 면의 정점은 화면 좌표가 아니라 머리 중심, 로컬 기준축과 머리 표면 위치로 정의한다.
- 머리 구, 얼굴 면과 머리카락·장식은 별도 출력 그룹과 깊이 순서를 가질 수 있다.
- 좌우 비대칭 요소를 고려해 왼쪽·오른쪽 기준을 구분한다.
- 완전 측면에서 반대쪽 얼굴 요소를 숨기거나 전환할 수 있어야 한다.
- 초기 단계에서는 표정 변형, 립싱크, 텍스처와 정밀 얼굴 메시를 포함하지 않는다.

### 검토 항목

- 하나의 정면 다각형, 복수 얼굴 패치 또는 머리 구 표면의 원호 기반 면 중 어떤 구조가 안정적인가
- 눈·코·입을 면 정점에 직접 연결할지 별도 로컬 좌표에 배치할지
- 시점 보간 중 코·턱·볼의 실루엣과 가림을 어떻게 전환할지
- PNG/SVG 출력과 그룹 병합에서 얼굴 내부선과 머리 외곽을 어떻게 구분할지

### 완료 조건

- 기본 얼굴 면이 머리 관절과 머리 구를 따라 정면·45도·측면에서 유지된다.
- 눈·코·입을 배치할 안정적인 기준점 또는 로컬 좌표가 있다.
- 반대쪽 얼굴 요소의 가림과 얼굴·머리·머리카락 순서가 정의돼 있다.
- 프로젝트 저장·복원과 포즈·월드 회전에서 얼굴 면 참조가 유지된다.

## R1. 리그 구조와 렌더링 표현 분리

### 데이터 상태

각 원본 관절·연결 면은 구조적으로 유지하고, 출력 상태만 다음 중 하나로 관리한다.

- `visible`: 원본 신체를 출력한다.
- `guide-only`: 편집 가이드·선택에는 보이지만 최종 출력에서는 숨긴다.
- `covered`: 지정한 의상 표면이 원본 신체를 덮는다.

의상은 가림 대상 체인 또는 연결 면을 명시한다. 원본 관절을 삭제하거나 부모 관계를 바꾸지 않는다.

### 완료 조건

- 긴소매가 `shoulder → elbow → wrist`의 원본 면을 가려도 세 관절을 모두 선택·회전할 수 있다.
- 가이드 표시 여부가 PNG/SVG 결과를 바꾸지 않는다.
- 의상 가림을 해제하면 원본 신체 렌더링이 복구된다.

## G1. 관절 단위 확장 표면

### 생성 규칙

의상 관절은 원본 관절 ID를 참조하고 다음 값만 추가한다.

- 반지름 또는 표면 폭 확장값
- 로컬 X/Y/Z 표면 스케일과 두께
- 색상·출력 레이어
- 인접 원본 관절과의 의상 연결 여부

확장 표면은 원본 관절의 부모·자식 관계, 축, 깊이, X/Y/Z 회전과 원근 투영을 상속한다. 원본 관절 거리·기본 깊이·포즈 데이터를 의상 편집 때문에 변경하지 않는다.

### 첫 에셋

- 팔 전체를 덮는 긴소매
- 다리 전체를 덮는 긴바지
- 손목 또는 발목에서 끝나는 단순 장갑·부츠

### 완료 조건

- 정면·측면·사선 포즈에서 소매와 바지가 원본 튜브를 따라간다.
- 체형 프리셋을 바꿔도 확장량과 의상 체인 연결이 유지된다.
- 관절 거리 비율은 포즈 전후 100%를 유지한다.

## G2. 의상 연결 면의 로컬 축 절단

### 규칙

절단은 화면 X/Y나 고정 월드 좌표가 아니라 부모 관절에서 자식 관절로 향하는 연결 면의 로컬 길이를 기준으로 한다.

- `cutStart`: 부모 쪽에서 숨길 구간
- `cutEnd`: 자식 쪽에서 숨길 구간
- 위치는 0~1 비율 또는 연결 면의 로컬 길이로 저장

### 예시

- 반소매: 어깨–팔꿈치 의상 면의 자식 쪽에서 절단
- 7부 소매: 팔꿈치–손목 의상 면을 중간 비율에서 절단
- 반바지: 엉덩이–무릎 의상 면에서 절단

### 완료 조건

- 같은 의상 정의가 포즈·원근·체형 변화 후에도 같은 신체 부위에서 끝난다.
- 절단면의 캡·외곽선·가림이 일관되게 출력된다.
- 절단 위치 변경은 원본 관절 또는 연결 길이를 바꾸지 않는다.

## G3. 통합 검증과 다음 단계 판단

### 검증 표본

1. 정면 기본 포즈의 긴소매·긴바지
2. X/Y/Z 회전이 있는 팔·무릎 포즈의 반소매·7부 바지
3. 깊이가 다른 두 체형에 같은 포즈와 의상을 적용한 표본
4. PNG, SVG, 스프라이트 시트 JSON, JSON 재불러오기, Unity 임포트 표본

### 완료 조건

- 편집 화면, 내보내기 미리보기, PNG/SVG, Unity 스프라이트에서 가림·길이·레이어가 동일하다.
- 저장·불러오기와 체형 전환 뒤에도 원본 리그와 의상 참조가 끊기지 않는다.
- 외곽선·원근 회귀 사례가 자동 테스트와 실제 파일 점검을 통과한다.

## 이후 범위

G3 이후에만 다음을 검토한다.

- 주름, 접힘, 늘어짐, 비대칭 실루엣
- 치마·망토·후드처럼 여러 체인 또는 체인 밖으로 퍼지는 의상
- 보조 제어점, 재봉선, 포즈별 보정과 물리 기반 변형
