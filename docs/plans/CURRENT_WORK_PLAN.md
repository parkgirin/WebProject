# 현재 작업 진행 순서와 완료도

이 문서는 현재 작업의 실행 순서와 완료도를 판단하는 기준이다. 세부 설계는 다른 문서를 참고하되, 서로 충돌할 때는 이 문서의 상태와 순서를 우선한다. 정확한 시간·날짜 추정은 두지 않고 선행 조건과 검증 결과로 다음 작업을 결정한다.

## 현재 작업 단위 — 체형·포즈 분리와 프로젝트 저장

목표는 체형의 기본 관절 배치와 포즈 변형을 분리하고, 고정된 출력 카메라를 기준으로 모델·애니메이션을 안전하게 저장·복원하는 것이다.

| 순서 | 작업 | 상태 | 확인 결과 |
| ---: | --- | --- | --- |
| 1 | 신체·포즈·외형·출력 시점의 데이터 소유권 정리 | 완료 | v3 데이터 계약과 문서 작성 |
| 2 | 기존 `Rig`와 v3 프로젝트 문서의 양방향 변환 | 완료 | 리그·신체·포즈·외형·출력 시점 변환 테스트 통과 |
| 3 | `baseOffset` XYZ와 체형 전환 보정 | 완료 | 아동체 방향, 목 길이 누적, 기본 포즈 깊이 문제 수정 |
| 4 | 회전 중 관절 거리 계산을 XYZ로 통일 | 완료 | 관절·동등 그룹의 회전 전후 거리 유지 테스트 통과 |
| 5 | 체형 기준 내장 포즈 정리 | 완료 | T 포즈 제거, 기본 포즈 초기화·팔 내림·30° 포즈를 `baseOffset` 기준으로 적용 |
| 6 | v3 프로젝트 JSON 저장·복원 | 완료 | 현재 모델, 포즈·월드 회전·외형 애니메이션 트랙 왕복 지원 |
| 7 | 체형 독립 포즈 적용 | 미완료 | Z 회전만 저장한 v2 포즈도 다른 체형의 관절 좌표를 덮어써 변형됨 |
| 8 | 실제 브라우저 파일·렌더링 왕복 점검 | 미완료 | PNG/SVG/애니메이션 ZIP 및 v3 프로젝트 파일을 실제 다운로드·재불러오기 해야 함 |

현재 작업 단위의 자동 검증 기준은 `npm.cmd test`와 `npm.cmd run build` 통과다. 실제 파일 출력과 브라우저 입력 검증은 자동 테스트와 별개로 수행한다.

## 다음 진행 순서

1. **체형 독립 포즈 적용 수정**
   - v2 포즈의 절대 `x/y/z`를 대상 체형에 그대로 대입하지 않는다.
   - 대상 체형의 `restOffset`에 포즈 회전, 방향 변화와 길이 배율만 합성한다.
   - 성인체↔아동체 양방향, Z 회전 전용 포즈, 깊이 포함 포즈를 회귀 테스트로 고정한다.
2. **렌더링·파일 왕복 우선 검증**
   - 편집 화면, 저장 미리보기, PNG, SVG와 애니메이션 프레임 결과를 비교한다.
   - `paint`/`overlay`/`cutout`, 중첩 합성, 카메라 회전과 투명 배경을 포함한다.
   - v3 프로젝트를 저장한 뒤 모델·현재 포즈·애니메이션·색상이 복원되는지 확인한다.
3. **게임용 애니메이션 출력**
   - PNG 스프라이트 시트와 프레임 메타데이터를 추가한다.
   - FPS, 루프 방식, 프레임 순서, 공통 경계와 피벗을 명시한다.
4. **출력 표현력 확장**
   - 의상용 튜브 셸과 그룹 병합 SVG를 구현한다.
   - 정밀 깊이 절단은 실제 교차가 에셋 제작을 막을 때만 승격한다.
5. **저장·편집 후속 이전**
   - 브라우저 자동 저장을 v3 구조로 이전한다.
   - 여러 애니메이션 클립 선택 UI와 런타임의 v3 직접 편집을 별도 작업 단위로 진행한다.

## 고정 결정

- 애니메이션 결과는 프로젝트의 고정 `outputView`에 비치는 상을 기준으로 한다.
- 카메라 애니메이션과 `ViewTrack`은 만들지 않는다.
- 캐릭터 전체 회전이 필요하면 포즈 트랙과 분리된 `worldRotationTrack`을 사용한다.
- 체형의 기본 자세는 각 체형의 `baseOffset`이며, 공통 T 포즈를 강제하지 않는다.
- 정확한 일정 시간보다 재현 가능한 완료 조건과 실제 출력 결과를 우선한다.
