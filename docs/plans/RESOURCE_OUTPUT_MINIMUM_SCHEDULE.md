# 리소스 출력 최소 기능 계획

## 목표

편집 중인 분리 도형 리그에서 게임 리소스로 사용할 수 있는 반복 가능한 애니메이션 이미지와 깨끗한 그룹 단위 SVG를 출력한다. 현재 실행 순서는 [현재 작업 진행 순서와 완료도](CURRENT_WORK_PLAN.md)를 따른다.

## 고정 데이터 규칙

- `outputView`는 프로젝트와 애니메이션 전체가 공유하는 고정 출력 카메라다.
- 카메라 애니메이션과 `ViewTrack`은 만들지 않는다.
- 캐릭터 전체 회전 애니메이션은 별도 `worldRotationTrack`에 저장한다.
- 포즈 트랙은 관절의 체형 기준 변형만 소유하며 카메라·원근 값을 변경하지 않는다.
- 편집 화면, 재생, PNG/SVG 프레임 출력은 같은 투영과 합성 경로를 사용해야 한다.

| M4 | 통합 검증과 교차 경고 | 미착수 |

## 진행 순서

### M0 — 회귀 입력과 출력 기준

- 정면·측면·45도와 체형 기본 자세·팔 내림·다리 교차 리그를 저장한다.
- 합성 그룹, 투명 배경, 고정 출력 경계와 피벗을 포함한다.
- 편집 화면, PNG와 SVG를 비교할 수 있는 기준 결과를 만든다.

### M1 — 편집·재생·출력 일치

- 관절 Z와 월드 회전을 포함한 프레임을 정지 화면·재생·PNG/SVG ZIP에서 비교한다.
- v3 프로젝트 저장 후 `outputView`, 포즈 트랙과 `worldRotationTrack`이 동일하게 복원되는지 확인한다.
- 포즈 저장·수정이 고정 출력 카메라를 변경하지 않는지 확인한다.

### M2 — 일반 튜브와 의상 셸

- 기존 팔다리의 카메라 대응 면을 재사용 가능한 `TubeSection` 계산으로 분리한다.
- 부모 튜브를 참조하는 `TubeShell`에 양 끝 반지름, 길이 오프셋, 색상과 출력 그룹을 둔다.
- 소매 하나를 기준 구현으로 만들고 정면·측면·45도와 애니메이션에서 확인한다.

### M3 — 그룹 병합 SVG

- 출력 그룹별로 투영된 원·튜브·셸·도형을 수집한다.
- 같은 그룹은 하나의 채움 경계로 병합해 내부선을 제거한다.
- 그룹 간 경계와 카메라 거리 순서는 유지하고 편집 가이드는 제외한다.

### M4 — 통합 검증과 교차 경고

- 실제 게임 에셋 한 개로 PNG/SVG/스프라이트 출력과 재불러오기를 점검한다.
- 부분 교차를 감지해 경고하되 자동 깊이 절단은 하지 않는다.
- 비교차 포즈에서 내부선, 보조선, 외곽선 누락이 없는지 확인한다.

## 완료 조건

- 같은 프레임이 편집 화면, 재생, PNG와 SVG에서 같은 카메라 기준 결과를 가진다.
- PNG 스프라이트 시트와 메타데이터에 FPS, 루프, 프레임 순서, 공통 경계와 피벗이 기록된다.
- 몸통·팔·소매가 지정된 출력 그룹별로 병합되고 내부선 없이 독립 SVG로 열린다.
- 알려진 교차는 경고되며 비교차 포즈는 반복 출력해도 결과가 변하지 않는다.
