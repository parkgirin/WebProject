# 도형 모드 전환 계획

> **상태: 계획.** Unity용 2D 캐릭터 일러스트 제작에서 머리·얼굴·헤어·의상·장식을 빠르게 만들 수 있도록, 리그 조작과 도형 제작의 작업 맥락을 분리한다. 이 문서는 모드를 새 데이터 형식으로 만들지 않으며 아직 구현하지 않는다.

## 1. 목적과 범위

- 현재 선택, 다각형, 선분, 점 추가, 점 연결 도구는 유지한다.
- 도형 모드는 이 도구들을 쉽게 찾고 도형만 안전하게 편집할 수 있게 하는 **UI 작업 공간 전환**이다.
- 리그의 관절·축·연결 면 데이터, 포즈, 출력 결과와 저장 형식은 모드 전환으로 달라지지 않는다.
- 머리 원도 다른 외형과 같은 원 `ArtShape`로 만들고, 도형 모드에서 생성·선택·크기·레이어를 편집한다.
- 베지어, 브러시, 텍스처 편집과 Unity 파일을 직접 쓰는 기능은 이번 모드 범위에 포함하지 않는다.

## 2. 모드 정의

| 모드 | 주 사용 목적 | 캔버스 선택 대상 | 기본 표시 |
|---|---|---|---|
| 리그 모드 | 포즈·관절·축·연결 면 편집 | 관절, 축, 면 | 관절·축 가이드·면 표시, 도형은 결과 확인용 |
| 도형 모드 | 머리·얼굴·헤어·의상·장식 제작 | 도형과 도형 꼭짓점 | 도형과 선택 핸들 표시, 리그는 참조·스냅용 가이드 |

모드는 상단의 하나의 토글 또는 `리그` / `도형` 두 탭으로 전환한다. 마지막 선택 대상과 각 모드의 마지막 도구를 별도로 기억한다. 도형 모드에서 도형이 하나도 없으면 원·다각형·선분 생성 행동을 첫 화면에 안내한다.

## 3. 도형 모드의 1차 UI

### 도구 상자

- 도형 선택, 원, 다각형, 선분, 점 추가, 점 연결, 색상, 레이어 순서만 앞에 노출한다.
- 원·다각형·선분을 `추가` 묶음으로, 점 추가·점 연결을 `정점` 묶음으로 배치한다.
- 팬·확대는 두 모드에서 공통으로 유지한다.
- 리그를 직접 바꾸는 관절 이동, 축 회전, 반지름 변경은 도형 모드의 기본 포인터 동작에서 제외한다. 리그 수정이 필요하면 리그 모드로 전환한다.

### 캔버스와 가이드

- 도형을 최우선 클릭 대상으로 두며, 겹치는 경우 현재 통합 출력 순서의 앞 항목을 먼저 선택한다.
- 관절 중심, 도형용 축, 축 끝점과 연결 면 외곽은 반투명 참조 가이드로 남긴다. 도형 모드에서 이 가이드는 리그 편집 대상이 아니다.
- 점 연결·도형 생성 중에만 관절 축 끝점의 스냅 범위와 이름을 강조한다.
- `리그 가이드 표시` 토글로 참조 가이드를 숨길 수 있으나, 연결된 도형의 실제 결과는 숨기지 않는다.

### 속성 패널

- 선택 도형: 이름, 종류, 채우기/외곽선, 불투명도, 그룹, 레이어, 잠금, 표시, X/Y·너비/높이·회전을 제공한다.
- 원: 중심 원본, 반지름 또는 너비/높이, 원/타원 비율 잠금, 관절 바인딩을 우선 노출한다.
- 다각형·선분: 기존 꼭짓점/끝점 바인딩과 선분 두께를 유지한다.
- 선택 꼭짓점: 좌표 원본, 오프셋, 연결·스냅·연결 해제를 제공한다.
- 여러 도형을 선택하는 기능은 공통 속성 편집이 준비된 뒤 추가한다. 1차 모드는 단일 도형 선택만 지원한다.

### 도형 그룹·기준점 연결 최적화 — 다음 우선 작업

현재는 도형을 선택한 뒤 꼭짓점마다 연결 대상을 고르고, 관절을 선택한 뒤 수동 축을 추가한다. 게임 캐릭터의 머리카락·의상·장식처럼 같은 부위에 여러 도형을 만드는 흐름에는 클릭 수가 많으므로, 다음 작업에서는 **도형 그룹의 공통 기준점**을 먼저 확정하고 그 기준을 도형과 새 축에 빠르게 적용한다.

- 도형 그룹을 선택하면 `기준 관절`과 선택적인 `기준 축`을 한 번에 지정한다. 그룹의 도형은 기본적으로 이 기준을 새 도형의 중심·첫 꼭짓점 연결 후보로 사용한다.
- 기준은 출력 레이어 그룹과 분리된 편집 메타데이터다. 레이어 그룹 변경만으로 도형의 바인딩이나 포즈 추종 대상이 바뀌지 않는다.
- 그룹 기준을 관절 중심에 연결하거나, 관절의 기존 축 끝점에 연결할 수 있다. `현재 위치 유지`와 `기준점으로 스냅`을 항상 분리해 의도치 않은 도형 이동을 막는다.
- `도형 축 추가` 명령은 도형 또는 도형 그룹을 선택한 상태에서 제공한다. 대상 기준 관절을 자동 제안하고, 새 축에는 `art-{도형 또는 그룹 ID}-{번호}`처럼 충돌 없는 ID, 기본 길이, 단일/대칭 끝점 옵션을 넣는다.
- 새 축은 리그 연결 면에 쓰는 축과 같은 `JointAxis` 저장 구조를 사용하되, 생성 UI에서 `도형용` 목적을 표시한다. 면이 참조 중인 축을 바꾸거나 제거할 때와 도형만 참조하는 축을 편집할 때의 경고 문구는 구분한다.
- 한 도형의 원 중심·다각형의 선택 꼭짓점·선분의 선택 끝점에 대해 `기준 관절`, `기준 축 끝점`, `연결 해제`를 같은 메뉴에서 제공한다. 여러 꼭짓점에 일괄 적용하는 기능은 단일 도형 흐름 검증 후 추가한다.
- 그룹 기준이나 새 축을 바꿀 때 영향을 받는 도형과 꼭짓점 수를 미리 보여 주고, 변경은 하나의 실행 취소 기록으로 묶는다.

### 연결 꼭짓점의 크롭 — 후속 보정 기능

축 끝점에 연결한 꼭짓점은 포즈 변화, 관절 반지름 차이 또는 긴 도형용 축 때문에 의도한 외곽보다 과하게 돌출할 수 있다. 이를 보정하기 위해 `크롭` 값을 각 `axis-point` 꼭짓점의 선택적 속성으로 추가한다.

- 크롭은 연결 기준점에서 꼭짓점 방향으로의 유효 길이를 `0~100%`로 제한하는 값이다. `0%`는 현재 연결 결과를 유지하고, `100%`는 기준점까지 완전히 접는다.
- 기준점이 축 끝점이면 축 끝점과 꼭짓점 오프셋으로 계산한 최종 위치를 기준점 쪽으로 보간한다. 스냅 연결된 꼭짓점은 오프셋이 `0`이므로 크롭 값이 외형을 바꾸지 않는다.
- 크롭은 도형의 원본 바인딩·축 길이·관절 반지름을 변경하지 않는 렌더·출력용 보정 값이다. 따라서 같은 축을 공유하는 다른 면이나 도형에는 영향을 주지 않는다.
- 속성 패널은 선택 꼭짓점의 `크롭 0~100%` 슬라이더와 숫자 입력을 제공하고, `0%로 초기화`를 함께 둔다. 여러 꼭짓점 일괄 크롭은 단일 꼭짓점 조작을 검증한 뒤 추가한다.
- JSON 저장/복원, 포즈 보간, PNG/SVG와 애니메이션 프레임 출력은 크롭 값을 같은 방식으로 반영한다. 축 또는 연결 원본을 바꿀 때는 현재 화면 위치 유지 정책과 크롭 값 유지/초기화 정책을 명시적으로 선택해야 한다.

도형 모서리의 **라운드 처리**는 이 크롭 기능과 별개다. 라운드는 SVG 경로·곡선·교차 처리, 선택 핸들 및 출력 호환성까지 필요하므로 직선 도형·원·크롭 기반의 게임용 제작 흐름이 안정된 뒤 장기 백로그로 검토한다.

완료 조건은 머리 그룹에 기준 관절 `head`를 지정하고 원·헤어 도형을 연속 생성한 뒤, 머리카락용 축 하나를 추가해 여러 꼭짓점 또는 중심을 빠르게 연결할 수 있는 것이다. 관절 이동·회전, 저장/복원, 포즈 보간과 PNG/SVG 출력에서 기준 연결 결과가 유지되어야 한다.

## 4. 상호작용 규칙

1. 모드 전환은 진행 중인 다각형/선분 생성을 먼저 취소하고, 실행 취소 기록에는 남기지 않는다.
2. 도형 모드의 빈 공간 클릭은 도형 및 꼭짓점 선택만 해제한다. 관절이나 면을 새로 선택하지 않는다.
3. 도형을 드래그하면 도형을 이동하고, 꼭짓점을 드래그하면 해당 꼭짓점 또는 원의 중심/크기 핸들을 편집한다.
4. `점 연결` 도구에서만 축 끝점이 클릭 가능한 대상이 된다. Alt+클릭의 스냅 정책은 기존 규칙을 그대로 사용한다.
5. 잠긴 도형은 캔버스에서 선택·이동·편집하지 못하며, 레이어 목록과 속성 패널에서 잠금 해제만 가능하다.
6. 도형 모드에서 만든 모든 변경은 리그 모드로 돌아와도 즉시 렌더, 저장, 보간 및 PNG/SVG 출력에 동일하게 반영된다.

## 5. 단계별 구현 계획

1. ~~원 도형 기반 마련과 기본 머리의 `head-base` 원 도형 이전~~
2. **도형 그룹·기준점 연결 최적화**: 그룹 기준 관절/축, 현재 위치 유지·스냅, 선택 요소의 일괄 연결을 추가한다.
3. **도형 축 추가**: 선택 도형/그룹의 기준 관절에 도형용 축을 빠르게 만들고, 길이·끝점·참조 경고를 편집한다.
4. **연결 꼭짓점 크롭**: 돌출 보정용 `0~100%` 값을 렌더·저장·보간·출력에 연결한다.
5. **모드 상태와 전환 UI**: `rig`/`shape` 작업 모드, 모드별 마지막 도구·선택 복원, 진행 중 생성 취소 규칙을 추가한다.
6. **도형 모드 입력 경계**: 도형 우선 히트 테스트, 리그 가이드의 비편집화, 점 연결 시에만 축 끝점 활성화, 키보드 단축키 범위를 적용한다.
7. **도형 전용 패널**: 원·다각형·선분 공통 속성과 원 전용 속성을 정리하고, 레이어 목록에서 도형 생성과 선택 흐름을 연결한다.
8. **검증**: 포즈가 바뀌는 동안 머리·헤어·의상 도형 바인딩, 도형/리그 모드 전환, 저장·불러오기, PNG/SVG 및 애니메이션 프레임 출력을 검증한다.

## 6. 완료 조건

- 기본 머리가 관절의 `bodyRadius` 출력이 아니라 선택 가능한 원 `ArtShape`로 렌더된다.
- 도형 모드에서 원, 다각형, 선분을 생성·선택·편집하고 축 끝점에 연결할 수 있다.
- 도형 모드의 클릭과 드래그가 의도치 않게 관절이나 면을 변경하지 않는다.
- 도형 모드에서 만든 결과가 리그 모드, 미리보기, JSON, PNG/SVG, 애니메이션 출력에서 일치한다.
- 기존 `bodyRadius` 기반 프리셋을 불러와도 시각적 머리 크기와 레이어 순서가 유지된다.
