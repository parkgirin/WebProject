# 자유 도형 생성·편집 계획

> **상태: 직선 다각형·두께 선분·원·구형 도형, 기본 머리 구 이전과 1차 제외 합성 구현.** 다음 작업은 합성 출력 검증을 마친 뒤 도형 그룹의 기준점 연결과 도형용 축 추가를 빠르게 만드는 흐름이다. 베지어 곡선, 자유곡선과 브러시는 현재 범위에 포함하지 않는다.

## 현재 구현 범위

- 다각형 도구로 꼭짓점을 추가하고 첫 점 클릭 또는 Enter로 닫기, Backspace로 마지막 점 제거, Esc로 생성을 취소한다.
- 일반 꼭짓점은 루트 좌표로, 축 끝점을 클릭한 꼭짓점은 `axis-point`로 저장한다. 데이터 구조와 좌표 계산은 독립 `self` 꼭짓점도 지원한다.
- 축 길이를 관절 반지름과 독립적으로 편집하며 기존 단일·대칭 끝점을 도형 연결에 사용할 수 있다.
- 도형과 꼭짓점을 선택해 드래그하고, 변 클릭으로 새 꼭짓점을 삽입하거나 선택 꼭짓점을 삭제한다.
- 생성 후에도 `점 연결` 도구나 속성 패널에서 축 끝점에 위치 유지 연결·스냅 연결·연결 해제를 실행한다.
- 선택 관절에 수동 축을 추가하고 길이·각도와 단일/대칭 끝점을 설정해 다각형에 사용할 수 있다.
- 리그 면을 선택해 면의 관절·축·끝점 참조, 색상과 그룹을 그대로 가진 자유 다각형을 바로 생성한다.
- 선분 도구로 두 끝점을 지정해 둥근 끝을 가진 두께 선분을 만들고, 끝점을 축에 연결하거나 두께·색상·레이어를 편집한다.
- 채우기 색상·레이어 순서·도형 삭제를 편집한다.
- 레이어 패널에서 관절·축 가이드·연결 면·자유 도형을 사진 편집 앱처럼 네 레이어로 분리해 레이어 전체를 일괄 표시·숨김한다. 레이어 내부 항목은 선택과 순서 확인용이며 개별 눈 아이콘은 두지 않는다. 관절·면·도형은 하나의 통합 출력 순서를 유지하고 축은 출력되지 않는 가이드 레이어로 분리한다.
- 프리셋 저장·복원, 키프레임 보간, 단일 이미지와 애니메이션 프레임 출력에 다각형과 선분을 포함한다. 두꺼운 선의 출력 경계에는 선 반폭을 반영한다.
- 원 도형과 카메라 투영을 따르는 구형 도형을 구현했다. 기본 머리는 `head` 관절 중심에 연결된 독립 `sphere` ArtShape이며, 일반 구는 루트에 독립 생성할 수 있다. `root`와 `self` 간 전환 UI, 다중 꼭짓점 선택, 경계 상자 크기·회전, 잠금·외곽선·불투명도는 미구현이다.
- 도형을 Shift+클릭으로 다중 선택해 하나의 합성 그룹으로 만들 수 있다. 그룹은 통합 스택 순서대로 첫 `paint`에서 시작해 이후 `paint`는 현재 결과와 교차하고, `overlay`는 현재 실루엣을 유지한 채 자신의 색을 내부에 올리며, `cutout`은 현재 결과에서 빠진다. 완전히 선택한 여러 기존 그룹은 새 상위 그룹 아래에 중첩할 수 있고, 자식 그룹의 결과를 부모에서 `paint`·`overlay`·`cutout` 피연산자로 사용한다. 선분은 두께 영역으로 `paint`와 `overlay`에 참여하지만 `cutout`은 허용하지 않는다. 제외·선택 가이드는 편집 화면에만 표시한다.
- 선택 도형과 꼭짓점은 방향키로 1px, Shift+방향키로 10px 평행 이동한다. Delete/Backspace는 편집 가능한 꼭짓점을 우선 삭제하고 그렇지 않으면 선택 도형을 삭제한다. Ctrl/Cmd+A는 도형 편집 중 모든 도형을 선택하며 Esc는 도형 선택을 해제한다. 다중 도형 이동·삭제는 각각 한 번의 실행 취소 단위다.
- Shift+도형 드래그는 최초 이동량의 우세 축을 기준으로 수평 또는 수직 이동하며, 이동 임계값 미만의 Shift 클릭은 다중 선택 전환으로 유지한다. Alt/Option+드래그는 현재 다중 선택을 독립 복제해 복제본만 이동한다. 복제된 도형끼리는 원본과 분리된 합성 그룹·중첩 계층을 유지하고 전체 복제·이동은 한 번에 실행 취소한다. Alt+Shift는 복제 이동과 축 제한을 함께 적용한다.

## 밀집 영역 선택과 성능 원칙

- `점 추가` 모드에서는 선택 도형의 변만, `점 연결` 모드에서는 꼭짓점과 축 끝점만 주요 클릭 대상으로 사용해 관절·면 드래그와의 충돌을 줄인다.
- 관절·축·끝점이 가까워 캔버스에서 구분하기 어려운 경우 속성 패널의 `관절 / 축 / ±끝점` 목록으로 대상을 확정한다. 화면 확대를 정확한 선택의 필수 조건으로 만들지 않는다.
- 선택된 꼭짓점이 축 끝점을 가리는 경우 연결 모드에서 그 꼭짓점의 포인터 입력을 통과시켜 아래 끝점을 선택할 수 있게 한다.
- 다음 개선은 같은 위치의 후보를 거리·레이어 순서로 수집해 반복 클릭으로 순환하는 방식, 관절/축/도형 종류별 표시 필터와 모바일용 확대 루페 순으로 검토한다.
- 현재 규모에서는 SVG의 대상별 이벤트 위임으로 충분하다. 수백 개 이상의 꼭짓점에서 포인터 탐색이나 전체 재렌더가 병목으로 확인될 때 화면 좌표 공간 인덱스와 변경된 도형만 갱신하는 증분 렌더를 도입한다.
- 공간 인덱스는 선택 후보 검색에만 사용하고, 실제 연결 관계와 렌더 순서의 기준은 계속 안정적인 ID와 모델 데이터로 유지한다.

## 1. 선행 작업 — 축 기반 꼭짓점 연결

도형 편집 UI보다 먼저 아래 데이터와 렌더 규칙을 완성한다.

1. 도형용 관절 축은 기존 `JointAxis` 규칙을 재사용하되 끝점 거리를 관절 반지름과 분리한다. 축 끝점은 관절 원 안쪽이나 바깥쪽에 있을 수 있다.
2. 단일 축은 `-1` 또는 `+1` 한쪽 끝점만 사용한다. 대칭 축은 양쪽 끝점이 중심·각도·길이를 공유한다. 대칭을 해제하면 한쪽 길이를 독립적으로 편집할 수 있게 확장할 수 있다.
3. 도형 꼭짓점 또는 원 중심의 좌표 원본은 다음 네 종류다.
   - `self`: 자신의 좌표를 직접 보유하며 관절과 모델 전체 회전의 영향을 받지 않는다.
   - `root`: 특정 관절에는 연결되지 않지만 모델 최상위 이동·회전·크기 변환을 따른다.
   - `axis-point`: `(jointId, axisId, side)`로 축 끝점을 참조하며 선택적인 로컬 오프셋을 가진다.
   - `joint-center`: 관절 중심을 참조하며 선택적인 로컬 오프셋을 가진다. 기본 머리 구는 `head` 관절 중심을 사용한다.
4. 좌표 원본을 변경할 때 현재 화면 위치를 유지하는 `연결/해제`와 끝점으로 즉시 이동하는 `스냅 연결`을 구분한다.
5. 연결 구조와 꼭짓점 순서는 모델 구조 데이터로 취급한다. 키프레임에서는 좌표·축 각도·축 길이·오프셋만 보간한다.

## 2. 직선 펜툴

### 필수 기능

- 빈 캔버스를 클릭해 직선 꼭짓점을 순서대로 추가한다.
- 첫 꼭짓점을 다시 클릭하거나 Enter를 누르면 도형을 닫는다.
- 최소 3개 꼭짓점이 있어야 도형을 확정한다.
- 입력 중 마지막 점부터 현재 포인터까지 미리보기 선을 표시한다.
- Backspace로 마지막 꼭짓점을 제거하고 Esc로 현재 생성을 취소한다.
- 생성 중 관절의 도형용 축 끝점에 포인터가 가까우면 스냅 후보를 표시한다.
- 일반 클릭은 `root` 또는 `self` 좌표를 만들고, 축 끝점 스냅은 `axis-point` 참조를 만든다. 기본 좌표 종류는 도구 옵션에서 고른다.
- 같은 위치의 연속 꼭짓점, 면적이 거의 0인 도형과 자기 교차는 확정 전에 경고한다. 첫 단계에서는 자기 교차 도형의 생성을 막는다.

### 이번 범위에서 제외

- 베지어 핸들, 곡선 구간과 자유곡선
- 연필·브러시 입력과 필압
- 도형 합치기·빼기·교차 같은 불리언 연산
- 자동 곡선 보정과 패스 단순화

## 3. 도형과 꼭짓점 선택

- 선택 도구로 도형 내부 또는 외곽선을 클릭해 도형 하나를 선택한다.
- 빈 캔버스를 드래그하면 선택 사각형과 화면 경계가 겹치는 원·다각형·두께 선분을 함께 선택한다. 일반 드래그는 기존 도형 선택을 교체하고 Shift+드래그는 기존 선택에 추가한다. 숨긴 도형 레이어와 숨긴 출력 그룹의 도형은 대상에서 제외한다.
- 선택된 도형에는 경계 상자, 중심점과 꼭짓점 핸들을 표시한다.
- 꼭짓점 핸들을 클릭해 점 하나를 선택하고 Shift+클릭으로 여러 점을 선택한다.
- 빈 공간 클릭으로 선택을 해제한다. 겹친 도형은 레이어 순서가 앞인 항목을 먼저 선택하며 반복 클릭 또는 목록으로 아래 항목에 접근한다.
- 잠금 또는 숨김 상태의 도형은 캔버스 선택 대상에서 제외하되 레이어 목록에서는 상태를 변경할 수 있다.
- Delete/Backspace 또는 속성 패널의 삭제 버튼은 선택된 꼭짓점이나 선택 도형 전체를 한 번에 삭제한다. 도형을 일괄 삭제하면 더 이상 사용하지 않는 합성 그룹 메타데이터도 함께 정리하며 한 번의 실행 취소로 복원한다. 꼭짓점 삭제 후 3개 미만이 되면 도형 삭제 여부를 확인한다.

## 4. 이동과 변형

### 캔버스 조작

- 도형 내부를 드래그하면 전체 도형을 이동한다.
- 꼭짓점 핸들을 드래그하면 해당 점만 이동한다.
- `self`와 `root` 꼭짓점은 각 좌표 공간에서 위치를 갱신한다.
- `axis-point` 꼭짓점은 기본 드래그 시 축 끝점 기준 오프셋을 변경한다. 스냅 명령은 오프셋을 0으로 만든다.
- 서로 다른 좌표 원본이 섞인 도형을 전체 이동할 때는 각 꼭짓점의 좌표 또는 오프셋을 같은 화면상 이동량만큼 변환한다.
- 경계 상자 핸들로 크기 조절과 회전을 제공한다. Shift는 비율 유지, Alt는 중심 기준 변형으로 사용한다.

### 숫자 입력

- 선택 도형의 X/Y, 너비/높이, 회전 각도를 입력할 수 있다.
- 여러 좌표 원본이 섞여 있으면 X/Y는 화면상 경계 상자를 기준으로 표시하며 변경값을 각 꼭짓점 공간으로 변환한다.
- 가로·세로 뒤집기, 90도 회전과 원래 크기 복원을 제공한다.

## 5. 원 도형

- 원 도구로 중심을 클릭하고 반지름만큼 드래그해 원을 추가한다.
- 기본은 가로·세로 반지름이 같은 원이며, 비율 잠금을 해제하면 타원으로 변경할 수 있다.
- 중심 좌표는 `self`, `root` 또는 `axis-point` 원본을 사용할 수 있다. 반지름은 중심 원본과 분리된 도형 값으로 저장한다.
- 선택 후 중심 이동, 반지름/너비/높이, 회전, 색상과 레이어를 편집한다.
- 원은 펜툴 곡선 지원과 별개의 기본 도형이다. 필요해질 때만 다각형 또는 곡선 패스로 변환하는 기능을 추가한다.

### 5.1 기본 머리 구의 도형 이전

기본 머리는 관절 본체가 아니라 `ArtShape`의 `sphere` 프리미티브다. 원과 달리 단일 모델 반지름을 가지며 카메라 깊이와 원근 투영 배율을 적용한다.

- 기본 리그는 `head` 관절에 연결된 `head-base` 구형 도형 하나를 생성한다. 중심은 `head` 관절 중심을 따라가고 기본 모델 반지름은 60이다.
- 초기 바인딩 영향은 이동 `1`, 회전 `1`, 변형 `0`으로 한다. 원형 머리는 회전해도 외관이 바뀌지 않지만, 이후 얼굴·머리카락과 같은 동일 관절 기반 도형의 규칙을 공유하기 위해 회전 바인딩을 명시한다.
- `head.radius`는 계속 목 면의 폭과 편집 가이드용 관절 반지름으로만 사용한다. 큰 머리의 출력 크기를 관절 반지름에 다시 묶지 않는다.
- 머리 구는 `head` 그룹에서 목 면보다 앞의 통합 출력 순서를 갖는다. 도형 레이어를 숨기면 다른 도형처럼 숨겨지고 관절 레이어와 독립적으로 동작한다.
- 이전 파일의 `head-base` 원은 로드 시 가장 큰 원 반지름을 유지한 `sphere`로 변환한다.
- PNG/SVG 미리보기·단일 내보내기·애니메이션 프레임·저장/복원·보간은 구형 도형을 동일하게 포함한다.
- 확인 기준은 기본 T 포즈와 머리 관절 이동·회전, 비율 프리셋 적용, 이전 형식 프리셋 불러오기, 도형 레이어 숨김 및 PNG/SVG 출력이다.

## 6. 모든 도형의 기본 변경 기능

- 이름 변경, 복제와 삭제
- 표시/숨김과 편집 잠금
- 채우기 색상, 외곽선 색상, 외곽선 두께와 외곽선 표시 여부
- 불투명도
- 그룹 지정과 레이어 순서: 한 단계 앞/뒤, 맨 앞/뒤
- X/Y 이동, 너비/높이, 회전, 비율 유지 크기 조절
- 가로/세로 뒤집기와 90도 회전
- 꼭짓점 추가·삭제 및 순서 변경
- 꼭짓점의 `self`/`root`/`axis-point` 원본 변경, 연결 해제와 스냅 연결
- 실행 취소·다시 실행
- JSON 저장·복원, PNG/SVG와 애니메이션 프레임 출력 반영

그라디언트, 텍스처, 블렌드 모드, 마스크와 클리핑 패스는 기본 변경 기능 이후 별도 작업으로 진행한다.

## 7. 옷 제작을 위한 후속 고려 사항

- 앞판·뒤판·소매·장식을 별도 도형으로 나누고 신체 부위 사이의 앞뒤 순서를 제어한다.
- 서로 다른 도형이 봉제선 또는 축 끝점을 공유해 포즈 변화에도 틈이 생기지 않게 한다.
- 신체 반지름과 독립된 축 길이·오프셋으로 품, 소매 폭과 밑단 너비를 표현한다.
- 겨드랑이, 팔꿈치, 사타구니와 무릎의 안쪽 접힘·바깥쪽 늘어남에 보정 꼭짓점을 둘 수 있게 한다.
- 여러 관절을 가로지르는 긴 옷은 고정 삼각형 분할과 가중치 바인딩으로 확장하고 뒤집힘과 과도한 늘어남을 검사한다.
- 옷 아래 신체 면을 가릴 범위, 소매 안쪽의 노출과 앞뒤 교차 포즈의 처리 규칙을 정의한다.
- 텍스처를 추가할 때는 도형 위상과 UV가 키프레임마다 유지되어야 한다.

## 9. 1차 완료 조건

- 직선 펜툴로 3개 이상의 점을 가진 닫힌 도형을 만들고 저장·복원할 수 있다.
- 독립, 루트와 축 끝점 꼭짓점을 한 도형 안에서 함께 사용할 수 있다.
- 관절과 도형용 축을 이동·회전하거나 축 길이를 바꾸면 연결된 점만 예상대로 따라간다.
- 연결을 해제하거나 좌표 원본을 바꿔도 요청한 정책에 따라 현재 화면 위치가 유지된다.
- 도형과 꼭짓점 선택, 이동, 크기·회전, 복제·삭제, 색상과 레이어 편집을 실행 취소할 수 있다.
- 원을 추가하고 원·타원 전환, 중심·크기·색상과 레이어를 편집할 수 있다.
- 편집 가이드와 축은 출력에서 제외되고 자유 도형은 단일 이미지와 모든 애니메이션 프레임에 포함된다.
- 키프레임 사이에서 도형 구조는 바뀌지 않으며 좌표·축·색상이 안정적으로 보간된다.
- `npm test`, `npm run build`와 브라우저 포인터 검증을 통과한다.
