# 일러스트 합성·반응형 편집 상태

이 문서는 합성과 반응형 편집의 상세 상태를 기록한다. 현재 실행 순서는 [현재 작업 진행 순서와 완료도](CURRENT_WORK_PLAN.md)를 따른다.

## 목표

페인트 브러시 없이 도형의 순서와 `paint`·`overlay`·`cutout` 합성으로 단색 2D 일러스트를 만들고, 같은 결과를 데스크톱과 작은 화면에서 편집·출력한다.

## 구현 완료

- 다각형·원·구·선분 도형 생성과 선택·이동·복제·삭제
- `paint`, `overlay`, `cutout` 순차 합성
- 합성 그룹 생성과 기존 그룹의 계층 중첩
- 다중 선택, 그룹 복제와 계층 보존
- 편집 화면의 제외 도형 가이드와 출력 제외
- 프리셋·키프레임·프로젝트 저장의 도형 및 합성 데이터 보존
- 좁은 PC, 세로·가로 모바일의 도구함과 설정·속성·월드·타임라인 공용 패널
- 모바일 실행 취소·다시 실행, 패널 도킹과 캔버스 공간 보정
- 원의 가로·세로 반지름 편집과 포즈 보간
- 자동 테스트 및 프로덕션 빌드 검증

## 남은 검증

| 순서 | 검증 | 완료 조건 |
| ---: | --- | --- |
| 1 | 저장 미리보기와 PNG | 투명 구멍, 중첩 그룹과 경계가 편집 화면과 일치 |
| 2 | 독립 SVG | mask/clip 참조가 외부 SVG 뷰어에서도 유효 |
| 3 | 애니메이션 PNG/SVG ZIP | 모든 보간 프레임에서 합성 결과와 공통 출력 경계 유지 |
| 4 | 반응형 실기기·브라우저 | 핵심 도구, 패널 스크롤, 포인터 좌표와 내보내기 접근 확인 |
| 5 | 오류 사례 | 빈 그룹, 부분 선택 중첩, 여러 cutout과 출력 경계 밖 가이드 확인 |

## 합성 규칙

| 값 | 역할 |
| --- | --- |
| `paint` | 첫 도형은 결과를 시작하고 이후 도형은 현재 결과와 교차 |
| `overlay` | 현재 외곽을 유지한 채 도형의 색과 무늬를 내부에 표시 |
| `cutout` | 같은 합성 그룹의 앞선 결과에서 자신의 영역을 제거 |
| `artCompositeGroups` | 자식 그룹 결과를 부모 그룹의 순차 피연산자로 사용 |

- `cutout`은 다른 루트 합성 그룹, 관절 원이나 연결 면을 지우지 않는다.
- 선분은 `paint`와 `overlay`에는 참여하지만 `cutout`이 될 수 없다.
- 편집 화면, 미리보기, PNG/SVG와 애니메이션은 같은 합성 규칙을 사용한다.

## 다음 연결 작업
