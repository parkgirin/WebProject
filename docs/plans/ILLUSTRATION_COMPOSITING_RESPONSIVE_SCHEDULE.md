## 목표와 완료 시점

현재 구현된 원·다각형·선분 도형 편집기를 바탕으로, **페인트 도구 없이도 겹치기와 비우기만으로 단색 2D 일러스트를 완성**할 수 있게 한다. 예를 들어 큰 원을 채움으로 그리고 작은 원을 같은 합성 그룹의 제외 도형으로 지정하면 도넛 모양을 만든다.

## 합성 설계 결정

단순 레이어 순서만으로는 안쪽 원을 투명하게 만들어도 아래의 다른 도형이 다시 보일 수 있어, 도넛 같은 구멍을 안정적으로 표현할 수 없다. 따라서 다음 규칙을 적용한다.

| 개념 | 데이터 값 | 화면/출력 규칙 |
| --- | --- | --- |
| 채움 도형 | `paint` | 첫 채움은 결과를 시작하고, 이후 채움은 현재 결과와 교차 |
| 오버레이 도형 | `overlay` | 현재 결과의 영역은 유지하고 도형의 색과 형태를 그 안에만 표시 |
| 제외 도형 | `cutout` | 같은 `compositeGroupId`의 앞선 `paint` 결과에서 자신의 영역을 투명하게 제거 |
| 합성 그룹 | `compositeGroupId` | 같은 ID의 `paint`·`overlay`·`cutout`을 하나의 SVG mask/clip 정의로 묶음 |
| 중첩 그룹 | `artCompositeGroups` | 자식 그룹의 합성 결과를 부모 그룹의 순차 피연산자 하나로 사용 |
| 편집 가이드 | 별도 표시 상태 | 제외 도형은 반투명 해치/점선으로 보이지만 PNG/SVG에는 표시하지 않음 |

- 도넛은 `outer-circle: paint`, `inner-circle: cutout`, 두 도형의 동일한 `compositeGroupId`로 만든다. `paint → cutout → paint`처럼 세 개 이상을 놓으면 앞에서부터 누적한 결과에 다음 연산을 적용한다.
- 바지 패치나 천 무늬는 바지 기반을 `paint`, 무늬 도형을 이후 `overlay`로 둔다. 무늬가 여러 도형이면 먼저 자식 그룹에서 합성하고 그 그룹 전체를 부모에서 `overlay`로 사용한다.
- 캔버스나 레이어 목록에서 Shift+클릭해 도형을 다중 선택하고, 선택한 도형으로 새 합성 그룹을 한 번에 만든다. 그룹 생성은 도형의 출력 레이어 그룹이나 합성 방식을 임의로 바꾸지 않는다.
- 기존 그룹의 도형을 빠짐없이 선택하면 여러 그룹을 새 상위 그룹 아래에 중첩한다. 일부만 선택한 그룹은 중첩하지 않으며, 자식 결과는 부모 안에서 `paint`, `overlay` 또는 `cutout`으로 지정한다.
- `cutout`이 다른 그룹이나 뒤쪽 항목까지 지우지 않게 하며, 대상이 없는 제외 도형은 오류 표시만 하고 출력에서는 무시한다.
- 선분은 시각적 두께 영역으로 `paint`와 `overlay`에 참여한다. 다각형과 원만 `cutout`이 될 수 있다.
- 기존 파일의 도형은 모두 `paint` 및 독립 합성 그룹으로 호환 로드한다.
- 합성은 SVG 편집 화면, 저장 미리보기, PNG/SVG, 애니메이션 모든 프레임에서 하나의 계산 함수를 공유한다.

## 완료 판정

- 두 원만으로 도넛을 만들고, 안쪽 원을 이동·크기 변경·선택할 수 있다.
- 제외 도형은 같은 합성 그룹의 채움만 투명하게 만들며, 다른 그룹과 리그 면을 지우지 않는다.
- 편집 화면, PNG, SVG, 저장 미리보기, 애니메이션 프레임의 합성 결과가 같다.
- 1440×900, 1024×768, 768×1024, 390×844에서 페이지 전체 스크롤 없이 핵심 편집과 내보내기가 가능하다.
- 모든 기존 자동 테스트 및 빌드가 통과한다.

## 1차 구현 메모 (2026-11-05)

- 그룹의 도형과 자식 그룹 결과를 통합 스택 순서대로 합성한다. 첫 `paint`가 결과를 시작하고, 이후 `paint`는 교차하며 `overlay`는 현재 결과 내부에 색을 올리고 `cutout`은 그 시점까지의 결과에서 빠진다. 따라서 다른 루트 합성 그룹, 관절 원, 연결 면은 지워지지 않는다.
- 도형 다중 선택으로 평면 그룹을 만들거나, 완전히 선택한 여러 그룹을 새 부모 아래에 중첩한다. 중첩 그룹도 동일한 순차 규칙을 재귀 적용하고 복제·프리셋 저장 시 계층을 보존한다.

## 모바일 레이아웃·화면 도구 1차 적용 메모 (2026-11-11)

- 1040px 고정 최소 폭을 제거하고 820px 이하 또는 짧은 가로 화면에서 캔버스 우선 단일 열로 전환한다.
- 툴박스는 기존 세로 구성을 유지한 왼쪽 플로팅 패널로 기본 노출하되 내용에 맞춰 높이와 폭을 잡는다. `도형/색상/보기` 내부 그룹은 기본으로 접어 캔버스 점유를 줄이고 상단 `도구` 버튼으로 전체 툴박스를 숨길 수 있다. 속성 패널은 기본 숨김 오른쪽 세로 드로어로 유지하며 타임라인도 작은 화면 진입 시 기본으로 접는다.
- 모바일 실행 취소·다시 실행은 캔버스 작업 영역 하단에 항상 노출한다. 화면 최하단은 클릭 빈도가 낮은 타임라인 키 목록이 차지하며, 펼친 타임라인은 제목/접기를 첫 줄, 재생·키 명령을 가로 스크롤 가능한 둘째 줄, 키 목록을 별도 셋째 영역에 배치한다.
- 모바일 상단 빠른 메뉴는 `도구/설정/속성/월드 회전`으로 구성한다. 타임라인은 자체 접기 버튼을 사용하고, 월드 회전은 설정 패널을 거치지 않고 팝업을 직접 연다.
- 모바일 월드 회전 패널은 도구창이 열려 있으면 도구창 오른쪽의 남은 폭만 사용한다. 좁은 비율에서는 `−90/+90` 빠른 회전 버튼을 숨기고 슬라이더와 숫자 각도 입력을 우선한다.
- 모바일 가로 화면은 별도 높이 규칙을 사용한다. 헤더·상단 도구·툴박스 간격을 줄이고 펼친 타임라인은 118px, 속성 패널은 최대 52vw로 제한하여 캔버스의 세로·가로 공간을 함께 확보한다.
- 가로 화면의 속성 패널은 캔버스를 덮는 드로어 대신 작업 영역 우측에 도킹하여 캔버스 폭을 줄인다. 월드 회전도 같은 흐름의 우측 세로 패널로 표시하고, 열릴 때 캔버스가 패널 너비만큼 줄어 편집 대상과 조작 UI가 겹치지 않게 한다.
- 월드 회전 패널은 속성 패널과 같은 `min(52vw, 336px)` 폭을 사용한다. 내부의 중복 닫기 버튼은 두지 않고 상단 빠른 메뉴로 여닫으며, 원근 강도는 라벨·슬라이더·숫자 입력을 한 행에 배치한다.
- 체형·포즈·월드·표시 옵션은 상단에 늘어놓지 않고 `설정` 팝오버에서 세로로 표시해 좁은 화면에서 잘리지 않게 한다.
- `화면` 도구는 단순 팬 토글 대신 모델 탐색 모드로 동작한다. 한 손가락 또는 마우스 드래그는 월드 X/Y 회전, 두 손가락 이동·핀치·비틀기는 각각 뷰포트 이동·확대·월드 Z 회전이다.
- 모델 회전은 기존 `worldRotation`에 기록되며 관절 선택과 포즈 데이터는 변경하지 않는다. 데스크톱의 우클릭 회전, Space/휠 버튼 화면 이동, 휠 확대는 유지한다.
- `cutout`은 편집 화면에서 점선 가이드로 선택할 수 있고 내보낸 SVG/PNG에서는 숨긴다. 합성 모드와 그룹은 인스펙터에서 변경하며 키프레임 전체에 구조 데이터로 동기화한다.
- 원 도형은 인스펙터에서 가로·세로 반지름을 독립 편집하며 실행 취소와 키프레임 보간에 반영한다. 제외 도형도 같은 선택·이동·크기 편집 경로를 사용한다.
- 다음 검증 작업은 C-12~C-16이다. PNG/SVG/애니메이션 ZIP 실제 파일 확인, 여러 cutout 중첩과 경계 밖 가이드의 출력 크기 영향을 확인한다.
