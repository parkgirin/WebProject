# 반응형 레이아웃 전환 계획

## 1. 목적

Pose Mesh Editor를 PC, 태블릿, 모바일에서 같은 편집 상태와 조작 규칙으로 사용할 수 있게 한다. 화면 크기에 따라 영역의 배치 방식은 달라지지만 캔버스 좌표, 선택 상태, 실행 취소 기록과 저장 결과는 바뀌지 않아야 한다.

페이지 전체에는 세로 스크롤을 만들지 않는다. 공간이 부족한 속성 내용은 지정된 패널, 드로어 또는 바텀 시트 내부에서만 스크롤한다.

## 2. 현재 상태

- PC 화면은 `헤더 / 왼쪽 도구 / 중앙 캔버스+하단 보간 바 / 오른쪽 속성 패널` 구조로 적용되어 있다.
- 앱 루트는 뷰포트에 고정되어 페이지 전체 스크롤을 막는다.
- 캔버스는 남은 폭과 높이를 사용하고, 속성 패널은 독립적으로 스크롤한다.
- 왼쪽 도구 열은 작은 고정 폭으로 유지하며, 오른쪽 속성과 하단 보간 바는 접을 수 있다. 레이아웃 전환 애니메이션은 사용하지 않는다.
- `body`의 최소 폭과 작은 화면용 고정 열 너비가 남아 있어 태블릿과 모바일은 아직 실제 반응형 레이아웃이 아니다.
- 속성 패널은 선택·레이어·색상 탭을 제공하지만 긴 선택 속성을 빈도와 난이도에 따라 접는 구조는 아직 없다.

## 3. 화면별 레이아웃

정확한 분기점은 콘텐츠가 겹치는 실제 폭을 기준으로 조정한다. 초기 구현 기준은 다음과 같다.

### 넓은 PC — 1200px 이상

- 상단 헤더 아래에 3열 작업 영역을 둔다.
- 왼쪽 도구 열은 `72px`, 오른쪽 속성 패널은 `336px`, 캔버스는 남은 공간을 사용한다.
- 중앙 열은 캔버스와 얇은 보간 바로 나누며 보간 바는 펼침 `112px`, 접힘 `44px`를 기준으로 한다.
- 속성 패널은 접을 수 있고 펼친 상태에서 패널 내부만 세로 스크롤한다.
- 현재 구현된 PC 구조를 기준으로 한다.

### 작은 PC·가로 태블릿 — 900px 이상 1200px 미만

- 왼쪽 도구 열과 캔버스를 유지한다.
- 속성 패널은 캔버스 위에 겹치는 오른쪽 드로어로 전환하고 열기·닫기 버튼을 제공한다.
- 헤더의 내보내기와 보조 명령은 메뉴로 묶어 캔버스 폭을 확보한다.
- 캔버스 툴바는 `체형`, `변형`, `표시` 그룹 단위로 줄바꿈하거나 메뉴로 접는다.

### 세로 태블릿 — 600px 이상 900px 미만

- 헤더를 축약하고 왼쪽 도구 열은 유지한다.
- 캔버스가 우선 공간을 차지하고 속성 패널은 하단 고정 영역 또는 확장 가능한 시트로 배치한다.
- 속성 패널을 닫았을 때 캔버스가 즉시 남은 높이를 사용해야 한다.

### 모바일 — 600px 미만

- 캔버스를 화면의 주 작업 영역으로 둔다.
- 왼쪽 도구 열은 하단 도구 막대로 바꾼다.
- 속성 패널은 바텀 시트로 열고 닫으며, 선택 대상 요약과 탭은 시트 상단에 고정한다.
- 헤더에는 문서명과 필수 명령만 남기고 저장·도움말·세부 표시 설정은 메뉴로 묶는다.
- 포인터 조작과 별도로 터치 대상은 최소 `44px` 크기를 확보한다.

## 4. 속성 패널 구성

화면 크기와 관계없이 정보 순서를 통일한다.

1. 현재 선택 대상과 선택 개수
2. 선택·레이어·색상 탭
3. 위치, 거리, 반지름, 각도처럼 자주 사용하는 값
4. 부모, 동등 관계, 가상 중심과 표시 설정
5. 축 정렬, 렌더 순서 계산 등 고급 설정

고급 설정은 기본적으로 접을 수 있게 한다. 탭이나 패널 배치가 바뀌어도 선택 대상과 입력 중인 편집 상태를 잃지 않아야 한다.

## 5. 구현 순서

1. 레이아웃 간격, 헤더 높이, 도구 폭과 패널 폭을 CSS 사용자 정의 속성으로 분리한다.
2. `body` 최소 폭을 제거하고 넓은 PC 레이아웃이 기존 모습과 동일한지 확인한다.
3. 작은 PC·가로 태블릿의 속성 드로어와 축약 헤더를 구현한다.
4. 세로 태블릿의 하단 속성 영역을 구현한다.
5. 모바일의 하단 도구 막대와 바텀 시트를 구현한다.
6. 속성 패널 내용을 공통 섹션으로 나누고 고급 설정 접기를 추가한다.
7. 각 화면 크기에서 캔버스 좌표 변환, 드래그, 확대·이동, 대화상자와 내보내기를 검증한다.

## 6. 완료 조건

- 1440×900, 1024×768, 768×1024, 390×844 화면에서 페이지 전체 세로 스크롤이 없다.
- 가로 스크롤 없이 주요 영역과 패널 열기 버튼에 접근할 수 있다.
- 속성 패널의 긴 내용만 패널 내부에서 스크롤한다.
- 화면 크기를 바꿔도 현재 리그, 선택, 활성 도구와 실행 취소 기록이 유지된다.
- SVG 포인터 좌표와 실제 관절 위치가 모든 화면에서 일치한다.
- 키보드, 마우스, 포인터·터치 입력으로 핵심 편집 기능을 사용할 수 있다.
- PNG/SVG 출력 결과는 화면 레이아웃과 무관하게 동일하다.
- `npm test`와 `npm run build`가 통과한다.
