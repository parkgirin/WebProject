# 예정 작업 문서

이 폴더는 아직 완료되지 않은 작업과 장기 설계를 모은다. 현재 동작을 설명하는 사양 문서는 `docs/` 루트에 유지한다.

[일러스트 합성·반응형 편집 일정](ILLUSTRATION_COMPOSITING_RESPONSIVE_SCHEDULE.md)은 도형 제외 합성(도넛 등)과 반응형 화면 최적화만을 대상으로 한 실행 일정이다.

## 현재 우선순위 — 게임 에셋 제작 기준

도구의 모든 편집 기능을 완성하는 것보다 **표현 가능한 캐릭터를 만들고, 게임에서 바로 쓸 수 있는 결과물을 반복해서 출력하는 흐름**을 먼저 완성한다.

1. **[자유 도형 생성·편집](SHAPE_EDITOR_PLAN.md)**
   - 머리, 얼굴, 머리카락, 옷과 장식처럼 현재 관절 원·연결 면만으로 표현할 수 없는 외형을 만든다.
   - 직선 다각형 생성, 생성 후 축 끝점 연결·해제, 꼭짓점 추가·삭제, 수동 축 추가, 도형·꼭짓점 이동, 색상·레이어·삭제와 저장·보간·출력 반영까지 구현했다.
   - 원 추가와 기본 머리 원의 도형 이전, 가로·세로 반지름 편집을 완료했다. 도형을 순서대로 교차·오버레이·제외하는 합성, 여러 도형의 평면 그룹화와 기존 그룹의 계층 중첩도 구현했다. `overlay`는 바지 패치처럼 기반 면의 외곽을 유지하면서 다른 도형 또는 자식 그룹의 무늬를 그 안에 표시한다. 다음은 합성 결과의 PNG/SVG/애니메이션 실제 파일을 검증한 뒤 [도형 모드 전환 계획](SHAPE_MODE_PLAN.md)의 그룹 기준점 연결로 진행한다. 펜툴 곡선은 현재 범위에서 제외한다.
2. **게임용 애니메이션 출력**
   - 현재 구현된 PNG/SVG 프레임 ZIP에 더해, 동일한 프레임 경계와 투명 배경을 사용하는 PNG 스프라이트 시트와 프레임 메타데이터를 우선 검토·구현한다.
   - 파일명, 프레임 순서, FPS, 루프 방식과 피벗을 명시해 엔진에서 재가공하는 비용을 줄인다.
3. **모델·프로젝트 전체 저장과 복원**
   - 리그, 도형, 색상, 레이어와 애니메이션 클립을 하나의 버전 있는 프로젝트로 저장해 에셋 제작을 이어갈 수 있게 한다.
   - 내보낸 게임 에셋과 편집 가능한 원본 프로젝트를 구분한다.
4. **핵심 모바일 편집을 위한 반응형 레이아웃**
   - [반응형 레이아웃 전환](responsive/RESPONSIVE_LAYOUT_PLAN.md)에 따라 이동 중에도 도형·포즈·애니메이션을 확인하고 핵심 값을 수정할 수 있게 한다.
   - 작은 PC, 태블릿, 모바일 레이아웃과 속성 패널 재구성을 진행하되 사용자 지정 패널 배치는 후순위다.
5. **커스텀 리그 제작**
   - 관절·축·면의 생성·삭제와 참조 무결성 UI를 추가해 기본 인체 이외의 게임 오브젝트를 만들 수 있게 한다.
6. **표현력 확장**
   - 텍스처, 여러 관절/면을 따르는 가중치 바인딩, 깊이·앞뒤 관계와 여러 모델 장면을 순차적으로 추가한다.

이미 구현된 [포즈 키프레임 보간](POSE_INTERPOLATION_PLAN.md)의 재생·중간 키 삽입·색상 보간·프레임 ZIP 출력은 위 작업의 기반으로 유지한다. 구간 눈금, 전환 프레임 수 입력, 클립 편집 히스토리 같은 타임라인 편의 기능은 에셋 출력에 막힘이 확인될 때 보완하고, 그렇지 않으면 위 핵심 제작 흐름 뒤에 진행한다. 3D 시점 회전과 카메라 확장은 계속 보류한다.

## 후속 작업 후보

- [범용 편집 기능과 장기 백로그](GENERAL_EDITOR_FEATURES.md): 사용자 지정 레이아웃, 관절·축·면 생성, 여러 모델, 도형·텍스처, 프로젝트 형식, PWA와 유사 3D 요구사항

세부 장기 순서는 범용 편집 문서에 모으고, 현재 우선순위는 이 문서의 `현재 우선순위 — 게임 에셋 제작 기준` 절을 기준으로 한다. 완료된 구현 내역은 코드·테스트와 프로젝트 인계 문서에서 관리하며 계획 폴더에 작업 일지를 중복 보관하지 않는다.

현재 리그, 자유 도형·합성 계층, 애니메이션 키프레임, 사용자 포즈·체형 프리셋과 편집 중인 프레임은 브라우저 로컬 저장소에 지연 자동 저장한다. 새로고침하면 유효성 검사를 통과한 최신 작업을 복원하고, 손상되었거나 이전 형식인 캐시는 무시한다. 파일 JSON 저장은 장기 보관과 다른 브라우저로 이동하기 위한 별도 기능으로 유지한다.
