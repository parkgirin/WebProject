# 예정 작업 문서

이 폴더는 아직 완료되지 않은 작업과 장기 설계를 모은다. 현재 동작을 설명하는 사양 문서는 `docs/` 루트에 유지한다.

## 현재 진행

1. [포즈 키프레임 보간](POSE_INTERPOLATION_PLAN.md)
   - 3개 이상 키의 메모리 모델과 구간 보간, 키 추가·수정·삭제·중간 키 승격, 애니메이션 JSON 저장·복원, 왕복/끝→처음 연결 재생을 구현했다.
   - 다음 구현은 키 사이 전환 프레임 수와 구간 눈금 UI다.
   - 3D 시점 회전과 카메라 확장은 보류한다.
2. [반응형 레이아웃 전환](responsive/RESPONSIVE_LAYOUT_PLAN.md)
   - PC 레이아웃의 뷰포트 고정과 세로 스크롤 제거는 적용했다.
   - 다음 구현 범위는 작은 PC, 태블릿, 모바일 레이아웃과 속성 패널 재구성이다.

## 후속 작업 후보

- [범용 편집 기능과 장기 백로그](GENERAL_EDITOR_FEATURES.md): 사용자 지정 레이아웃, 관절·축·면 생성, 여러 모델, 도형·텍스처, 프로젝트 형식, PWA와 유사 3D 요구사항

세부 장기 순서는 범용 편집 문서에 모으고, 현재 우선순위는 이 문서의 `현재 진행` 절을 기준으로 한다. 완료된 구현 내역은 코드·테스트와 프로젝트 인계 문서에서 관리하며 계획 폴더에 작업 일지를 중복 보관하지 않는다.
