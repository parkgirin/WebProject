# 2.5D 시점 회전 구현 문서

## 1. 목적과 범위

이 기능은 3D 메시·카메라·물리 기반 렌더러를 구현하지 않는다. 관절 기반 2D 리그에서 정면과 좌·우 측면 사이의 **위치, 크기, 앞뒤 겹침 변화가 어떤 결과를 만드는지 확인하는 시뮬레이션**이다.

따라서 다음을 제공한다.

- 관절별 깊이와 전역 투영 강도
- 캔버스 세로축(Y축) 기준 시점 회전
- 완전 측면에서도 연결 면이 사라지지 않도록 하는 실루엣 보존
- 정면 반지름과 측면 반지름의 보간
- 면·관절·가이드·히트 영역이 같은 파생 관절 크기를 사용하도록 하는 일관성

실제 타원 관절, 자유형 아트, 텍스처, 진짜 원근 카메라와 3D 법선은 이 단계의 범위 밖이다.

## 2. 핵심 원칙

### 면은 독립 도형이 아니라 관절 간 연결이다

면의 꼭짓점은 항상 `(jointId, axisId, side)` 참조에서 파생한다. 시점 회전 중에도 면을 별도로 이동·스케일하지 않는다.

```text
관절의 현재 시점 중심·반지름·축 방향
  → 관절별 화면 축 끝점
  → 면의 꼭짓점
  → 면 렌더링
```

따라서 관절의 화면상 크기가 바뀌면, 그 관절에 연결된 모든 면도 같은 반지름 기준으로 다시 생성된다.

### 화면상 직교는 정면 전용 규칙이다

정면에서는 관절 중심 연결선과 단면 축이 화면에서 직교한다. 그러나 3D 공간의 직교 관계는 일반 투영 뒤의 화면 2D 직교를 보장하지 않는다. 특히 완전 측면에서는 중심 연결선이 점 또는 짧은 선으로 수렴해 직교 방향을 안정적으로 정할 수 없다.

현재 시뮬레이션은 축을 실제 3D 벡터로 투영하지 않는다. 대신 관절 중심은 시점 변환하고, 축은 현재 화면 반지름과 기존 축 방향으로 다시 계산한다. 이는 면의 폭과 연결 관계를 유지하기 위한 의도적인 2D 보정이다.

## 3. 데이터 모델

```ts
interface Joint {
  radius: number;       // 정면(0°) 기준 반지름
  sideRadius?: number;  // ±90°에서 쓸 반지름. 없으면 radius 사용
  depth?: number;       // 앞(+) / 뒤(-) 깊이
}

interface Rig {
  projectionStrength: number; // 0..100
  viewYRotation: number;      // -90..90도
  silhouetteRetention: number; // 0..50, 완전 측면 가로 실루엣 보존율
}
```

`sideRadius`, `depth`, `viewYRotation`, `projectionStrength`, `silhouetteRetention`은 JSON 프리셋에 선택적으로 저장한다. 이전 v1 프리셋에 이 값이 없으면 기본 리그 값과 정면 반지름을 유지한다.

## 4. 계산 순서

각 렌더 프레임의 순서는 아래와 같다.

1. 관절의 로컬 좌표와 계층으로 월드 중심을 계산한다.
2. `viewYRotation`과 `depth`를 적용해 화면 중심과 최종 깊이를 계산한다.
3. 정면 반지름과 측면 반지름을 보간한다.
4. 깊이 기반 투영 배율을 관절 반지름에 적용한다.
5. 관절 중심, 보간된 반지름, 현재 축 방향으로 화면 축 끝점을 계산한다.
6. 축 끝점을 이어 면을 생성하고, 깊이·그룹·레이어 순서로 렌더한다.

### 측면 반지름 보간

`t = abs(viewYRotation) / 90`으로 정규화한다.

```text
currentRadius = radius + (sideRadius - radius) × t
```

예를 들어 `radius = 48`, `sideRadius = 24`인 허리는 `0°`에서 48, `45°`에서 36, `±90°`에서 24가 된다.

### 실루엣 보존

순수 Y축 투영은 `±90°`에서 같은 깊이의 X 좌표를 한 선으로 붕괴시킨다. 그러면 수평 팔처럼 두 관절 중심이 겹쳐 연결 면의 길이가 0이 된다.

이 편집기는 실제 3D 렌더러가 아닌 리그 동작 확인 도구이므로, 완전 측면에서 원래 X 간격의 일부를 남긴다. `silhouetteRetention`이 0이면 순수한 붕괴를, 값이 클수록 연결 면이 읽히는 넓은 측면 실루엣을 만든다. 기본값은 18%다.

## 5. 편집 방법

선택 패널에서 다음 순서로 조절한다.

1. `Y축 시점 회전`을 `±90°` 근처로 옮긴다.
2. `측면 실루엣 보존`을 조절해 팔다리와 몸통의 연결 면이 읽히는 최소 폭을 확보한다.
3. 각 관절의 `깊이`를 조절해 앞뒤 위치와 앞쪽 확대 정도를 맞춘다.
4. 허리·골반·어깨처럼 정면과 측면의 폭이 다른 관절은 `측면 반지름`을 설정한다.
5. `투영 강도`를 조절해 깊이에 따른 화면상 크기 변화를 정한다.
6. 마지막으로 그룹/레이어 순서를 조절해 앞다리·뒷다리·몸통의 겹침을 확정한다.

`±90°`는 기준 측면의 확인에 적합하며, 섬세한 직접 조작은 `±60°` 부근이 더 안정적이다. 깊이·시점 투영 때문에 역변환이 필요한 입력이 있기 때문이다.

## 6. 현재 한계와 후속 작업

- `sideRadius`는 원 반지름 하나를 보간하는 방식이다. 허리처럼 가로·세로가 다른 실제 타원 단면은 만들지 않는다.
- 하나의 면은 평균 깊이로 정렬되므로, 면 일부만 다른 면 앞에 와야 하는 깊이 교차는 해결하지 못한다.
- 숨김 관절 면 연장은 정면(`viewYRotation = 0`)에서만 사용한다. 시점 회전 중에는 새 화면 축 끝점과의 불일치를 피하기 위해 비활성화한다.
- 정면과 측면의 관절 위치·축 방향을 직접 저장하는 `ViewShapeKey`는 아직 없다. 현재 Y축 회전은 측면 배치를 위한 시뮬레이션·검증 단계다.

다음 단계에서는 `ViewShapeKey`에 정면·좌측·우측의 관절 위치, 반지름, 축 방향, 깊이 및 렌더 순서 보정을 저장하고, 두 키 사이를 보간한다. 실제 타원 또는 자유형 `ArtShape`는 그 이후에 추가한다.

## 7. 검증 기준

- `0°`에서 기존 정면 리그와 동일한 결과를 낸다.
- `±90°`에서도 가로 실루엣 보존값이 0보다 크면 연결 면의 길이가 0으로 붕괴하지 않는다.
- 측면 반지름을 바꾸면 관절 표시, 축 끝점, 연결 면이 모두 같은 보간 반지름을 사용한다.
- 깊이와 시점 회전을 저장한 프리셋을 다시 열면 같은 결과가 복원된다.
- 포인터 입력은 투영된 화면 좌표를 원래 리그 좌표로 역변환해 관절 조작이 가능해야 한다.
