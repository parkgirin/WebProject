# File presets

공유받은 프리셋 JSON을 종류에 맞는 폴더에 넣으면 다음 빌드부터 편집기 목록에 자동으로 나타난다.

- `body/*.json`: 체형 프리셋. 인체 비호환의 전체 리그 파일은 편집기의 `비인체 실험실`에서만 선택한다. 이 경로는 현재 조작·포즈·저장 호환성이 완전하지 않은 실험적 기능이며, 인체 에셋 작업을 우선한다.
- `pose/*.json`: 포즈 프리셋

파일 하나에는 프리셋 하나만 저장한다. 가장 간단한 방법은 앱의 `저장/불러오기 > JSON 저장`으로 만든 파일을 원하는 폴더에 그대로 복사하는 것이다. 비율·포즈 프리셋은 고정 인체 템플릿 `human-v1`을 사용한다. `body` 폴더의 인체 프리셋은 체형 정보만 적용하고, 전체 리그 파일은 비인체 실험실에서만 구조를 교체한다. `pose` 폴더에서는 저장된 관절 방향과 회전을 적용하되 현재 체형의 관절 간 거리와 루트 위치는 유지한다. 파일명이 목록의 표시명이 된다. 폴더 프리셋은 편집기에서 적용할 수 있지만 삭제할 수 없는 읽기 전용 항목이다.

표시명과 고정 ID를 직접 지정하려면 다음 공유 프리셋 형식으로 감쌀 수도 있다. 이 형식을 사용할 때 각 `id`는 같은 종류 안에서 고유해야 한다.

체형 공유 프리셋 형식:

```json
{
  "id": "shared-body-example",
  "name": "공유 체형",
  "createdAt": "2026-11-07T00:00:00.000Z",
  "preset": {
    "format": "pose-mesh-editor",
    "version": 2,
    "createdAt": "2026-11-07T00:00:00.000Z",
    "rigTemplate": "human-v1",
    "proportions": { "joints": [[5, -80, 0, 22]] }
  }
}
```

포즈 파일은 동일한 바깥 구조를 사용하고 `preset.proportions` 대신 `preset.pose`를 넣는다. `joints`의 첫 값은 고정 인체 템플릿의 관절 인덱스이며, 포즈 항목은 `[인덱스, x, y, 회전, 깊이, 축 각도 배열, 선택적 거리 비율]`, 체형 항목은 `[인덱스, x, y, 반지름, 선택적 측면 반지름]` 형식이다. 거리 비율은 체형의 관절 기준 거리 대비 백분율이며 `100`은 원래 길이다. 필요한 관절만 넣을 수 있다.
