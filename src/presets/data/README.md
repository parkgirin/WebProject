# File presets

공유받은 프리셋 JSON을 종류에 맞는 폴더에 넣으면 다음 빌드부터 편집기 목록에 자동으로 나타난다.

- `body/*.json`: 체형 프리셋
- `pose/*.json`: 포즈 프리셋

파일 하나에는 프리셋 하나만 저장한다. 가장 간단한 방법은 앱의 `저장/불러오기 > JSON 저장`으로 만든 파일을 원하는 폴더에 그대로 복사하는 것이다. `body` 폴더에서는 체형 정보만 적용한다. `pose` 폴더에서는 저장된 관절 방향과 회전을 적용하되 현재 체형의 관절 간 거리와 루트 위치는 유지한다. 파일명이 목록의 표시명이 된다. 폴더 프리셋은 편집기에서 적용할 수 있지만 삭제할 수 없는 읽기 전용 항목이다.

표시명과 고정 ID를 직접 지정하려면 다음 공유 프리셋 형식으로 감쌀 수도 있다. 이 형식을 사용할 때 각 `id`는 같은 종류 안에서 고유해야 한다.

체형 공유 프리셋 형식:

```json
{
  "id": "shared-body-example",
  "name": "공유 체형",
  "createdAt": "2026-11-07T00:00:00.000Z",
  "preset": {
    "format": "pose-mesh-editor",
    "version": 1,
    "createdAt": "2026-11-07T00:00:00.000Z",
    "hierarchy": {},
    "proportions": { "joints": {} }
  }
}
```

포즈 파일은 동일한 바깥 구조를 사용하고 `preset.proportions` 대신 `preset.pose`를 넣는다. 실제 파일에는 저장 대상 관절 전체가 필요하다.
